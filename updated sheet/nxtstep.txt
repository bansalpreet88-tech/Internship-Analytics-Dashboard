✓ Loaded AccidentsBig.csv
✓ Created Calculated Fields:
   • Hour                      → DATEPART('hour', [Time])
   • Severity Label            → IF [Accident_Severity]=1 THEN "Fatal"
                                   ELSEIF [Accident_Severity]=2 THEN "Serious"
                                   ELSE "Slight" END
   • Month/Year                → DATENAME('month', [Date]) + " " + STR(YEAR([Date]))
   • Urban/Rural Label         → IF [Urban_or_Rural_Area]=1 THEN "Urban"
                                   ELSE "Rural" END
   • Day of Week Name          → DATENAME('weekday', [Date])

📊 STEP 1: CREATE 7 WORKSHEETS (Do in order)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

─── WS1: Accident Trend Over Time ───
  • New Worksheet → Rename "WS1_Trend"
  • Columns: [Month/Year] (right-click → Discrete)
  • Rows: Number of Records (CNT(Accident_Index))
  • Marks: Line
  • Right-click X-axis → Edit → Tick Marks → Major tick marks = "Every month"
  • Label: "Accident Trend Over Time"


─── WS2: Accidents by Hour ───
  • New Worksheet → Rename "WS2_Hour"
  • Columns: [Hour]
  • Rows: Number of Records (CNT)
  • Marks: Bar
  • Sort: Hour ascending
  • Label: "Accidents by Hour of Day"
  • X-axis: Edit → Range → Fixed 0-24


─── WS3: Severity Distribution ───
  • New Worksheet → Rename "WS3_Severity"
  • Rows: [Severity Label]
  • Columns: Number of Records (CNT)
  • Marks: Bar
  • Color: [Severity Label]
    – Right-click Color → Edit Colors → Set:
      • Fatal = Red (#E31837)
      • Serious = Orange (#FF7F00)
      • Slight = Green (#4CAF50)
  • Label: "Accidents by Severity"


─── WS4: Weather Conditions ───
  • New Worksheet → Rename "WS4_Weather"
  • Rows: [Weather_Conditions]
  • Filters: Exclude "Unknown" (if present)
  • Columns: Number of Records (CNT)
  • Marks: Bar
  • Sort: Count descending
  • Label: "Accidents by Weather"


─── WS5: Road Type Analysis ───
  • New Worksheet → Rename "WS5_RoadType"
  • Rows: [Road_Type]
  • Columns: Number of Records (CNT)
  • Marks: Bar
  • Filter: Exclude null/blank
  • Sort: Count descending
  • Label: "Accidents by Road Type"


─── WS6: Geographic Map ───
  • New Worksheet → Rename "WS6_Map"
  • Double-click: [Latitude] → becomes rows
  • Double-click: [Longitude] → becomes columns
  • Tableau auto-generates map
  • Marks: Circle
  • Color: [Severity Label] (same red/orange/green)
  • Size: Number of Records (or set to 10 fixed)
  • Filters: Exclude null Latitude/Longitude
  • Map Style: Format → Map → Style = "Light" or "Normal"
  • Label: "Accident Locations by Severity"


─── WS7: Heatmap (Day vs Hour) ───
  • New Worksheet → Rename "WS7_Heatmap"
  • Columns: [Day of Week Name] (or [Day_of_Week] → convert to names)
  • Rows: [Hour]
  • Marks: Square
  • Color: Number of Records (CNT)
    – Edit Colors → Palette = "Red-Black-Green Diverging"
    – Center = 0 or median
  • Label: Show counts on cells (Mark → Label → Show mark labels)
  • Label: "Accident Heatmap: Day vs Hour"

─── Implementation ───

1. Drag a "Vertical" container to dashboard
2. Inside it (top): Drag a "Horizontal" container for KPIs
3. Create 3 KPI text objects:
   • Total Accidents = WINDOW_SUM(CNT(Accident_Index))
   • Total Casualties = SUM(Number_of_Casualties)
   • Fatal Accidents = {FIXED: SUM(IF [Severity Label]="Fatal" THEN 1 END)}
   Format: Large font (24-32pt), bold, colored background

4. Below KPIs: Add another Horizontal container
   Left: Drag WS2_Hour sheet
   Right: Drag WS3_Severity sheet

5. Below that: Add another Horizontal container
   Left: Drag WS4_Weather
   Right: Drag WS5_RoadType

6. Below: Drag WS6_Map (full width)

7. Optional: Add WS7_Heatmap as separate tab, not on main dashboard

🎛️ STEP 3: ADD FILTERS (Apply to ALL sheets)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Drag these to Filters (on each worksheet OR to dashboard):

• YEAR([Date]) → 2018, 2019, 2020 (select all years)
• [Weather_Conditions] → Exclude "Unknown"
• [Road_Type] → Exclude null/blank
• [Severity Label] → All
• [Urban/Rural Label] → All

On Dashboard:
  Right-click each filter → "Apply to Worksheets" → "Selected Worksheets" → Check ALL

Show filters on dashboard:
  Right-click filter in dashboard → "Show Filter" (UI controls for user)

  Clearing selections: Keep or Show all

This makes clicking any chart filter the entire dashboard.
